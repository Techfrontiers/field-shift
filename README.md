# FieldShift — ตัดสินใจหมุนเวียนพืชด้วยข้อมูล NASA

**NASA Space Apps Challenge 2026 — Challenge 7: Field Shift: Adapting Farms with NASA Data.**
Team SYDEAR, solo. Event online Nov 14–15, 2026. Submission due Nov 15, 23:59 local (Bangkok).

## ปัญหา (Problem)

ชาวนาที่ตำบลสมอแข อ.เมืองพิษณุโลก ปลูกข้าวเป็นหลัก แต่ฝนมาช้า-มาเร็วไม่แน่นอน
ร้อนจัดขึ้น และน้ำในฤดูแล้งไม่พอ — จะปลูกอะไรต่อจากข้าวดี? ปลูกข้าวซ้ำทุกปี
ดินจะโทรมไหม? ถ้าเปลี่ยนไปปลูกถั่วหรือพืชคลุมดินในฤดูแล้ง จะคุ้มไหม?
ชาวนาไม่มีเครื่องมือเปรียบเทียบทางเลือกแบบเห็นตัวเลข — ตัดสินใจจากประสบการณ์
และความจำอย่างเดียว

## เครื่องมือ (What it does)

เครื่องมือช่วยตัดสินใจหมุนเวียนพืช (crop-rotation decision-support) สำหรับ**ข้าว**
หนึ่งแปลง โดยเปรียบเทียบ **3 กลยุทธ์** จากข้อมูลภูมิอากาศย้อนหลังของ NASA POWER
(ไม่ใช่พยากรณ์) แล้วจัดอันดับตาม**ความสำคัญของชาวนาเอง** (ผลผลิต / น้ำ / รายได้ /
สุขภาพดิน / ความเสี่ยง) — ชาวนาเป็นคนตัดสินใจ เครื่องมือแค่ช่วยให้เห็นภาพ

- **A — ข้าวเดี่ยว (ปัจจุบัน):** ข้าวฤดูฝน แล้วปล่อยว่างฤดูแล้ง
- **B — ข้าว + ถั่ว:** ข้าวฤดูฝน แล้วปลูกถั่ว (พืชตระกูลถั่วตรึงไนโตรเจน) ในฤดูแล้ง
- **C — ข้าว + พืชทนแล้ง/พืชคลุมดิน:** ข้าวฤดูฝน แล้วปลูกพืชทนแล้งหรือพืชคลุมดิน
  ในฤดูแล้งเพื่อรักษาความชื้นและสุขภาพดิน
- ข้าวเป็นพืชหลักในทุกกลยุทธ์ B/C เพิ่มพืชช่วงว่าง/ฤดูแล้งเท่านั้น

## ข้อมูลจริง (Real data — ไม่ใช่ตัวเลขสมมติ)

- **แปลง:** ต.สมอแข อ.เมืองพิษณุโลก — พิกัด 16.829678N, 100.362797E
  (พิกัดตำบลชั่วคราว; พิกัดแปลงจริงจะมาแทนที่ + ดึง POWER ใหม่)
- **NASA POWER** (ดูไฟล์ใน `data/`):
  - `power_climatology.json` — ค่าเฉลี่ยรายเดือน 25 ปี (2001–2025):
    ฝนสูงสุด ก.ย. 7.86 มม./วัน, ต่ำสุด ธ.ค. 0.29 มม./วัน;
    อุณหภูมิเฉลี่ยสูงสุด เม.ย. 29.94°C, ต่ำสุด ธ.ค. 21.51°C
  - `power_daily_2024.json` — รายวันทั้งปี 2024 (ฝนรวม 1,360 มม.;
    ฤดูฝน พ.ค.–ต.ค. 241/135/247/257/213/157 มม.;
    ฤดูแล้ง พ.ย.–เม.ย. แห้งมาก; ฝนเริ่มตกจริง 6 พ.ค. 2024;
    อุณหภูมิสูงสุด 42.9°C)
- **ดิน (SoilGrid v2, `data/soilgrid.json`):** ดินร่วนปนดินเหนียว
  (clay ~30%, silt ~40%, sand ~31%), pH 6.3, อินทรียวัตถุ 2.56%
  (0–5 ซม.) — เก็บน้ำได้ดี เหมาะกับข้าว
- **ข้อจำกัดที่ต้องพูดตรงๆ:** POWER เป็นกริด ~50 กม. (ค่าของแปลงใกล้เคียง
  ไม่ใช่ค่าที่แปลงโดยตรง); เครื่องมือนี้เปรียบเทียบจากประวัติศาสตร์
  **ไม่ใช่พยากรณ์** — ไม่รับประกันผลผลิต

## หลักการ (Rules)

- เปรียบเทียบแบบมีเงื่อนไขจากข้อมูลประวัติศาสตร์ — ไม่ใช่พยากรณ์
- "ดีกว่า" ขึ้นกับความสำคัญของชาวนา (เลือกได้) — ไม่มีการจัดอันดับเดียว
- ตัวเลขทุกตัวต้องมาจากข้อมูลจริง หรือระบุชัดว่าเป็นสมมติฐาน/ค่าประมาณ
- ชาวนาเป็นคนตัดสินใจ — เครื่องมือสนับสนุน ไม่ใช่แทนที่
- ภาษาไทยเป็นหลัก (ชาวนาใช้) + อังกฤษ
